# NAME

**paramux** - native Windows terminal workspace for parallel coding agents

# DESCRIPTION

Paramux is a native Windows terminal workspace for running multiple coding
agents in parallel. It combines a GPU-accelerated terminal with split panes,
tabbed workspaces, live pane metadata, attention states, and local automation.

Paramux remains compatible with existing shells and terminal software while
retaining Ghostty-compatible terminal protocols and resource conventions where
interoperability requires them.
